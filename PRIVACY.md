# Privacy Policy — ROBRUN TR

**Publisher:** ICESTAR  
**Product:** ROB RUN Türkçe Yama (`ROBRUN_TR.exe`)  
**Site:** https://robrunturkceyama.com/

## Summary

The desktop installer is designed to run **locally**. It does not require an account.

## Data processed on your PC

| Data | Purpose | Leaves the PC? |
|------|---------|----------------|
| Selected ROB RUN folder path | Validate game files / pass `--game` to worker | No |
| Addressables cache files | Install/remove Turkish patch | No (local disk) |
| Process list (game running check) | Block install while game is open | No |
| Optional HTTPS GET to `release.json` | Version / SHA-256 advisory | Yes — only release metadata request |

## Website

The marketing site may count downloads via a simple server-side counter. No advertising tracker is required by this project. See the hosted site’s own notices if additional analytics are later added.

## No selling of data

We do not sell personal information. The installer does not embed analytics SDKs in the current codebase.
